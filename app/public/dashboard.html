IMPORT CONSOLE

Bulk import

POST a batch to /api/v1/import. The endpoint inflates Content-Encoding: br/gzip and accepts up to a 50 MB compressed body.

New import

Or upload compressed, over the wire

# Brotli-compress the batch, then POST it brotli -q 5 batch.json -o batch.json.br curl -X POST http://localhost:3000/api/v1/import \ -H 'Content-Type: application/json' \ -H 'Content-Encoding: br' \ --data-binary @batch.json.br
